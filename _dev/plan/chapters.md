# ステップ5：章の段階一覧（案）— メロディ章とコード章

方針
- マップは「メロディ → コード → ベース → 構成」を1本の道（地続き）で並べる。
- メインの道＝「基本」。これだけで次の章へ進める。
- 難しい内容は、道の横に生えた「寄り道ステージ」（やらなくても先へ進める）。寄り道は小さめの丸で、点線でつなぐ。
- **いま学習中の生徒さんを混乱させないため、すでにあるレッスン（3-1〜3-7、4-1〜4-5）はすべてメインの道に残す**（番号・クリア記録・図鑑の条件は変えない）。寄り道は新しく足すものだけ。
- 寄り道の番号は「3-A」のようにアルファベットにして、メインの番号（クリア記録・章クリア・図鑑のカード条件）と混ざらないようにする。

## マップの見せ方（案）
- 第3章〜第6章を、横にスクロールする1本の道としてつなげる（章の区切りは旗で見せる）。
- 寄り道ステージは、メインのステージの上（または下）に小さな丸で出し、点線でつなぐ。「よりみち」のラベルと、やらなくても先へ進めることを示す文（「やらなくても先へすすめるよ」）。
- 寄り道をクリアすると、丸に★が付く。章クリアの判定には入れない。
- 寄り道のレッスンを作るまでは「じゅんび中」の小さな丸として出す（押すと「もうすぐ遊べるよ」）。→ 見た目が増えて混乱しそうなら、作ったものだけ出す（確認事項）。
